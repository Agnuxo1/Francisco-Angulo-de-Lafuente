## Maintenance rules

- Prefer official project, publisher, event or bibliographic pages.
- Label first-person, historical and catalogue material instead of presenting it as independent verification.
- Do not infer awards, scientific priority, performance, adoption or endorsement from a repository description.
- Re-run `python scripts/validate_profile.py` after changing the profile or this ledger.
